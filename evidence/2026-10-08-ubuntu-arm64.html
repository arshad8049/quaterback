The 755 → 757 difference. The first unit run had the three QB_SANDBOX_*_IMAGE overrides exported (below). Two tests (test/unit/qb-cli.test.js and test/unit/qb26-ci-evidence.test.js) assert the default content-tagged image name, and received claude-code@2.1.288 (sha256:c3352fc9…) instead. Clearing the overrides for the rerun resolved both. No code or assertions changed. (Since then, both tests clear those variables themselves.)

Why the paired test was blocked. At admission the sandbox requires host MemAvailable of at least the per-run peak plus a reserve: 9.13 GiB + 2 GiB = 11.13 GiB with the default limits (lib/sandbox/admission.js). The guest had 7.7 GiB in total, so the gate refused the run, as designed. This is not evidence of incorrect grading, ARM incompatibility or task failure. The gate was not loosened.

Integration summary: 3 tests, 2 passed, 1 failed, 0 skipped. The integration suite is not reported as green.

Commands and configuration

Exactly what was run

Images were built manually and tagged qb-sandbox-tools:latest, qb-sandbox-agent:latest and qb-sandbox-proxy:latest (QB normally builds and selects content-derived tags itself). The terminal then pinned them by image ID:

export QB_SANDBOX_TOOLS_IMAGE="$(docker image inspect qb-sandbox-tools --format '{{.Id}}')"
export QB_SANDBOX_AGENT_IMAGE="$(docker image inspect qb-sandbox-agent --format '{{.Id}}')"
export QB_SANDBOX_PROXY_IMAGE="$(docker image inspect qb-sandbox-proxy --format '{{.Id}}')"

First unit run, with those overrides set (755 / 757): npm test.

Unit rerun, with the overrides cleared for that process only (757 / 757):

env -u QB_SANDBOX_TOOLS_IMAGE -u QB_SANDBOX_AGENT_IMAGE -u QB_SANDBOX_PROXY_IMAGE npm test > /tmp/qb-unit-tests-default.log 2>&1

Docker integration tests, with the overrides kept (2 / 3). These use a scripted agent and mocked QB model replies with real Docker containers; no paid model task was started:

QB_INTEGRATION=1 node --test --test-concurrency=1 test/integration/qb28-experiment.test.js test/integration/qb29-image-binding.test.js > /tmp/qb-docker-tests.log 2>&1
