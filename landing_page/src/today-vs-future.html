You stopped writing the code. Now you check the agent.

Writing code with a coding agent is fast. Checking whether it actually completed the request still takes work. Quarterback structures that check in three steps.

01

Approve the task.

Review the requirements and checks before the coding agent starts.

02

Run and check.

Quarterback supplies repository context, executes the agent in isolation and runs the approved checks. Failed checks can feed another repair attempt.

03

Review the result.

Inspect the proposed patch and its evidence before applying changes to your repository.
