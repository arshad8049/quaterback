The builder does not grade its own work.

An agent that says it is done is telling you what it believes, not what is true. Quarterback checks the work separately, with its own evidence.

The loop we refuse to ship
Builder: “I interpreted the task this way.”
Builder: “I implemented my interpretation.”
Builder: “I reviewed my work and confirm my interpretation was implemented.”
Hard evidence first

Facts that are not up for debate come before any opinion.

your project’s own tests, before and after the change
the checks you approved (for example: this function returns that value)
an exact record of every changed file
a guard on which files may change and which must not

Planned, not yet built: type checking, linting, browser tests, and security and dependency checks.

Judgment second

A separate reviewer model answers what tests cannot:

Was each approved requirement actually met?
What evidence supports that, and what is missing?
Was any requirement quietly skipped?

Without evidence, a judgment cannot turn a run into a pass.
