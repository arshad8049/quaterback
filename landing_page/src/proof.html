These are the results, with where each one was measured. Accepted work has regression coverage and CI across Node 20, 22 and 24, plus Docker integration tests.

Replayable from its own evidence
Each run keeps a versioned record: the exact starting commit, the agent version, the test report and the checks. Replaying it recomputes the verdict, and a record whose outcome its evidence does not support is flagged.
