Correctness before cost
Correctness, then human attention, then time, then tokens. Inference gets cheaper every year. Senior engineering attention does not.
Local-first by default
The client runs on your machine and its own model calls stay local by default. The coding agent you choose sends your task and code to its provider; telemetry is off unless you turn it on.
No new IDE
A command-line tool next to the coding agent and editor you already use. If it does not reduce your review work, uninstall it.
